Estimation Tool Disclaimer

This tool is an estimation calculator for the operating time of S&C "K" Speed Fuse Links using TripSaver II TCC curves. It applies the selected fuse curve constants to approximate the expected melting/clearing time based on the fault current and parameters you provide.

🚫 This calculator must NOT be used as the basis for any final engineering determination, protection coordination study, fuse sizing decision, or equipment design. Results are approximate and intended solely as a preliminary reference to estimate operating time. Always verify results using certified relay-coordination software and consult a qualified protection engineer before making any operational or design decision.
